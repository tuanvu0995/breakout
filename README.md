# Brickstellar

A flat, colorful brick breaker made with Godot 4: fly a ship-paddle with an
upgradable gun through 120 levels in 12 worlds, beat a boss at the end of each
world and take down THE ARCHITECT.

- Game: Godot 4.7 project in this folder (`com.pixalab.brickstellar`)
- API (leaderboards, OTA): Cloudflare Worker in `server/api`, served at `bs-api.pixalab.co` - see `server/api/DEPLOY.md`
- OTA patches: `tools/build_patch.sh`
- Credits: `CREDITS.md`
